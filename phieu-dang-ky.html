⚠️ Trang chưa được cấu hình: vui lòng mở file HTML này và điền WEBAPP_URL bằng đúng URL Web App đã Deploy từ Apps Script.
⚠️ Không kết nối được tới máy chủ Google Sheets (WEBAPP_URL). Vui lòng kiểm tra:
  1. Deployment trên Apps Script đã chọn "Who has access: Anyone" chưa (không phải "Anyone with Google account")?
  2. Đã tạo deployment MỚI (hoặc bấm "Manage deployments" > sửa deployment cũ) sau lần sửa code .gs gần nhất chưa? Sửa code mà không deploy lại thì URL cũ vẫn chạy code CŨ.
  3. WEBAPP_URL trong file HTML này có đúng dạng .../exec (không phải /dev) và không thừa/thiếu ký tự khi copy không?
  4. Thử mở thẳng URL đó trên trình duyệt kèm ?action=ping ở cuối (VD ...exec?action=ping) - nếu hiện chữ JSON {"success":true,...} là server ổn, lỗi nằm ở CORS khi gọi từ tên miền ngoài; nếu không hiện được (trang lỗi/màn hình đăng nhập Google) là do Deployment sai quyền truy cập.
